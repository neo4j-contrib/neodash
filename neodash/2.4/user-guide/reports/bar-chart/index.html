Bar Chart

This documentation pertains to the (legacy) unsupported version of NeoDash. For users of the supported NeoDash offering, refer to NeoDash commercial.

A bar chart will draw categories and values in a familiar bar-layout. The bar chart will require you to choose the following selections:

  • Category: a text field. These will be the labels on the bars.

  • Value: a numeric field. This will be the height of the bars.

  • Group: Optionally, a second textual field. When ``Grouping'' is enabled in the advanced settings, the group can be used to draw a stacked bar chart, with several groups per category.

Examples

Simple Bar Chart

MATCH (p:Person)-[e]->(m:Movie)
RETURN m.title as Title, COUNT(p) as People

Stacked Bar Chart

Match (p:Person)-[e]->(m:Movie)
RETURN m.title AS Title, COUNT(p) as People, type(e) as Role

If enabled, the chart will no longer autofit to the size of the report card. If width extends beyond the report card, a scroll bar will be introduced to explore the chart horizontally.

auto

If not set to ``auto'', this variable is minimum value for the bar chart.

Max Value

auto

If not set to ``auto'', this variable is the maximum value for the bar chart.

Group Mode

List

stacked

This setting determines how different groups are visualized when grouping is enabled. If set to stacked, different groups of the same category are stacked on top of each other. If set to grouped, they are placed alongside each other.

Layout

List

vertical

Whether to use a vertical or horizontal bar chart layout.

Color Scheme

List

The color scheme to use for the category groups. Colors are assigned automatically (consequitevely) to the different groups returned by the Cypher query.

off

If enabled, shows the category value inside the respective bar.

Only active when 'Custom Dimensions' is on. The width of each bar. Increasing the bar width will increase the width of the chart. This setting will have the largest influence on the width of the chart.
